# Reality section photos

This folder holds **exactly 2 photos** used by the "The Reality" section on the home page.

- `photo-1.webp` — small image (left on desktop)
- `photo-2.webp` — large image (right on desktop)

To swap the images, replace these two files **keeping the same file names**. Do not add more than 2 photos here — only `photo-1` and `photo-2` are read by the site.
